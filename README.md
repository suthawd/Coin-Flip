# Coin Flip

A minimal one-button web app. Press **Flip Coin** to get Heads or Tails.

## Run locally

```bash
cd coin-flip
py -m http.server 8081
```

Open [http://localhost:8081](http://localhost:8081).

## Deploy to GitHub Pages

Push this folder to a repo named `coin-flip`, then enable GitHub Pages on the `main` branch root.
